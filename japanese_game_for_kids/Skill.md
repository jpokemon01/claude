# Skill.md — japanese_game_for_kids

Skills and knowledge relevant to this directory.

## Early Childhood Language Learning

- Age-appropriate design for 3-year-olds: audio-first (pre-readers), large touch targets, immediate positive feedback, no penalties for mistakes
- Vocabulary selection: concrete everyday nouns (animals, food, colors, numbers) before abstract words or writing systems
- Repetition through play: flashcard exposure followed by listen-and-find quiz

## Web Development

- Single-file HTML/CSS/JavaScript game, no build tools or dependencies
- Web Speech API (`speechSynthesis`) for native Japanese pronunciation (`ja-JP` voice)
- CSS animations for reward feedback (confetti, pop, wobble)
- Responsive layout with `clamp()` sizing — works on phone, tablet, and desktop

## Japanese Language

- Hiragana-first vocabulary display (ねこ, りんご, あか…)
- Natural quiz phrasing: 「〜は どれ？」("Which one is ~?")
- Praise phrases: すごい！ やったね！ じょうずだね！ せいかい！
