# Skill.md — translate_english_portuguese

Skills and knowledge relevant to this directory.

- Identifying Brazilian Portuguese vs. European Portuguese differences
- Legal and vital-records terminology in both languages
- Reading source documents from scanned PDFs (`English/` folder)

## Document Production

- Python with `reportlab` — formal certificate-style PDF layout (`generate_pdfs.py`): Times fonts, tables, horizontal rules, A4 pages
- Markdown authoring of translations (`Portuguese/` folder), with matching PDF output
- Document formatting and localization conventions for official Brazilian paperwork
