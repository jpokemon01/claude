# Skill.md — portuguese_game

Skills and knowledge relevant to this directory.

## Adult Language Learning & Memory

- Spaced repetition (Leitner system) — expanding review intervals (1/3/7/14/30 days) to fight forgetting; the single most effective technique for adult vocabulary retention
- Dual-anchor meanings: showing both English and Japanese leverages the learner's two strong languages for better recall
- Self-graded flashcards (Hard/Easy) — active recall beats passive re-reading
- Accessibility for older learners: large type, high contrast, slow-playback audio

## Brazilian Portuguese

- pt-BR vocabulary selection for practical use: greetings, numbers, food, travel, everyday phrases
- pt-BR vs pt-PT voice selection in the Web Speech API (prefer `pt-BR` voices)
- Portuguese orthography in seed data (ã, õ, ç, é, ê accents)

## Web Development

- Single-file HTML/CSS/JS app; Supabase REST + anon key with embedded fallback (same pattern as japanese_game_for_kids)
- `localStorage` for per-device spaced-repetition state
- Web Speech API mobile quirks: gesture unlock, cancel/speak delay, late voice loading
